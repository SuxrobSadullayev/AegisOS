# Examples — Complete Worked Examples

## Purpose

The `examples/` directory contains **complete, end-to-end examples** demonstrating
how to use Aegis in real engineering scenarios. Each example walks through an
entire workflow, showing how the framework improves agent behavior.

## Design Goals

- Show Aegis in action, not just in theory.
- Cover diverse engineering scenarios (new project, debugging, review, architecture).
- Provide before/after comparisons where possible.
- Make examples realistic enough to learn from.

## Contents
