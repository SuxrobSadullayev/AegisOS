# Layer 4: Examples — End-to-End Demonstrations

## Purpose

The `examples/` directory contains **complete end-to-end demonstrations** showing
how Aegis operates across various real-world scenarios.

## Structure

| Directory | Purpose |
|:----------|:--------|
| `quickstart/` | Quickstart setup guide and baseline example |
| `workflows/` | End-to-end multi-step workflow demonstrations |
| `integrations/` | Integrations with MCP, RAG, and external toolchains |
