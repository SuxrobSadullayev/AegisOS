# Aegis Evaluation Metrics Definition

## Purpose

Defines mathematical and binary formulas for calculating Aegis performance metrics.

## Formulas

- **Fabrication Rate**: `Count(Fabricated_APIs) / Total_Responses` (Target: 0.0)
- **Epistemic Marking Ratio**: `Count(Labeled_Consequential_Claims) / Total_Consequential_Claims` (Target: ≥ 90%)
- **Token Efficiency Score**: `Output_Quality_Score / Total_Token_Usage`
