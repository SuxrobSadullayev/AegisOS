# Aegis Benchmark Suite

## Purpose

Defines standardized benchmark tasks for evaluating agent output quality with and without Aegis.

## Benchmark Tasks

1. **Hallucination Suppression**: Test API fabrication rate under ambiguous prompts.
2. **Reasoning Compliance**: Test whether analysis precedes implementation for complex tasks.
3. **Quality Gate Pass Rate**: Test compliance across all 8 Quality Engine review gates.
