# Languages — Language-Specific Engineering Standards

## Purpose

The `languages/` directory contains **language-specific engineering modules**.
Each language module provides tailored standards, idioms, anti-patterns, and
checklists for writing production-quality code in that language.

## Design Goals

- Provide language-specific guidance beyond generic "clean code" advice.
- Cover idiomatic patterns that agents frequently miss.
- Address common pitfalls specific to each language's type system, memory model, or runtime.
- Complement (not duplicate) the general engineering modules.
